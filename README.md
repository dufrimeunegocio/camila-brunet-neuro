# Camila Brunet Neuropsicologia

Crie um site profissional, moderno, sofisticado e responsivo para a neuropsicóloga Camila Brunet, especializada em avaliação neuropsicológica e serviços relacionados à área de Neuropsicologia.

A imagem anexada neste prompt é uma referência visual da profissional e deve ser utilizada como base para a identidade visual e, quando apropriado, como imagem da profissional no site. Preserve uma apresentação natural, profissional e elegante.

1. OBJETIVO DO SITE

O principal objetivo do site é apresentar a atuação profissional de Camila Brunet, explicar de forma simples e acessível o que é a avaliação neuropsicológica, apresentar os serviços oferecidos e transformar visitantes em potenciais pacientes/clientes.

O site deve transmitir:

Profissionalismo

Credibilidade

Acolhimento

Segurança

Clareza

Sofisticação

Precisão técnica

Humanização

Evite uma estética infantil, excessivamente feminina ou com aparência de clínica médica genérica.

A comunicação deve ser profissional, mas compreensível para pessoas que não possuem conhecimento técnico em Neuropsicologia.
